📖 Como usar o crawler

Para atualizar as promoções:

1. Abra o terminal no diretório do projeto

2. Execute o comando:

python crawler.py

O que acontece:

  • O crawler busca produtos de bebê na Amazon
  • Salva no banco de dados (produtos.db)
  • O site mostra automaticamente as novas promoções

Quantos produtos são salvos?

O crawler salva até 30 produtos por execução, evitando sobrecarga.
